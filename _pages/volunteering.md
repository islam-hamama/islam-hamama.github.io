## Python Basics + AI Agents — Pre-Al Amal 18

*Volunteer workshop · August 2026*

A free, hands-on workshop for **geoscience graduates with no programming background**:
from your very first `print()` statement to reading, checking and fixing code written by
an AI agent. Everything is run live in **Google Colab**, so nothing needs to be installed
to follow along.
